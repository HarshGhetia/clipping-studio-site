7Trades Clipping Studio

Privacy policy

Last updated 13 November 2026

7Trades Clipping Studio (shown on Google's sign-in screen as “7Trades Clipping Studio”) is a personal tool that runs entirely on its owner's computer. This policy says what it does with the information it gets from Google when the owner connects a YouTube channel.

YouTube API Services

7Trades Clipping Studio uses YouTube API Services. By connecting a channel you also agree to the YouTube Terms of Service, and Google handles your information under the Google Privacy Policy.

What it accesses

  • The connected channel's ID, name, handle and picture, to show which channel clips go to.
  • The channel's playlists, so the owner can pick one for new clips.
  • The view, like and comment counts of videos 7Trades Clipping Studio itself published, to show which clips work best.
  • Sign-in tokens from Google, so it can publish without asking the owner to sign in each time.

It uploads videos, thumbnails, subtitle tracks, playlist entries and the owner's own first comment, only for clips the owner approved or set to publish automatically. It never deletes videos and doesn't read anyone else's private information.

Where it's kept

Everything stays on the owner's computer, in 7Trades Clipping Studio's data folder. Sign-in tokens are stored encrypted (AES-256-GCM). Nothing is sent to a server run by 7Trades Clipping Studio; there is none.

Sharing

Information obtained through the YouTube API is not sold, not shared and not used for advertising. To pick moments and write titles, 7Trades Clipping Studio sends the transcript of the source video and its public details (title, channel name) to the AI service the owner chooses (such as Anthropic's Claude); it doesn't send them anything it got from the YouTube API with the owner's permission. There are no ads and no third-party analytics.

Cookies

7Trades Clipping Studio's own interface runs on the owner's computer and sets a single sign-in cookie there, only when the owner protects it with a password. This website sets no cookies.

Keeping and deleting

Information is kept until the owner disconnects the channel or deletes 7Trades Clipping Studio's data folder. Disconnecting a channel in 7Trades Clipping Studio's settings deletes its stored tokens. You can also remove 7Trades Clipping Studio's access at any time in your Google account's third-party access settings.

Children

7Trades Clipping Studio isn't meant for children and doesn't knowingly handle children's information.

Changes and contact

Changes to this policy are posted on this page with a new date. Questions: open an issue on GitHub.
